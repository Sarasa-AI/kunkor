# ADR-6 — لایه انتزاعی ارائه‌دهنده مدل (وابستگی اصلی با Fallback)

**وضعیت:** accepted (اصلاح‌شده تحت ADR-0009)  
**تاریخ اصلی:** 2026-10-22  
**تاریخ اصلاح:** 2026-11-03

## تصمیم

لایه انتزاعی ارائه‌دهنده مدل الزامی است.

برای **مشاوره کامل و خودمختار**، AI یک وابستگی اصلی runtime است (نه اختیاری).  
با این حال:

- Provider Abstraction اجباری است
- Fallback و Degraded Mode اجباری است
- در صورت قطعی یا محدودیت Provider، سیستم باید وارد حالت امن و محدود شود و برنامه پشتیبانی‌نشده فعال نکند

## دلیل

- مشاوره خودمختار چندعاملی بدون مدل ممکن نیست
- وابستگی سخت به یک Provider ریسک عملیاتی و هزینه‌ای ایجاد می‌کند
- رفتار degradable از فعال‌سازی برنامه‌های بی‌پایه جلوگیری می‌کند

## پیامدها

- رابط `complete(prompt_id, inputs) → structured`
- مدیریت timeout، retry، 429 و budget
- ارسال داده فقط پس از حذف شناسه‌ها (PII Masking)
- قابلیت خاموش‌کردن Provider خاص
- ثبت model/provider version در هر AgentRun و SupervisorDecision
