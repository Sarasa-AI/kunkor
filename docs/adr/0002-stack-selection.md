# ADR-2: پشته فنی (Next.js, FastAPI, PostgreSQL)

- **وضعیت:** پذیرفته شده
- **تاریخ:** 2026-10-23
- **مرجع:** بخش ۲٫۱ مشخصات پروژه

## زمینه و مسئله
نیاز به توسعه سریع، پشتیبانی خوب از RTL و زبان فارسی در رابط وب، قابلیت اطمینان بالا در API، و پایگاه داده رابطه‌ای سازگار با داده‌های ساختاریافته و شواهد آموزشی.

## تصمیم
- رابط وب: Next.js + TypeScript با پشتیبانی بومی از RTL و طراحی واکنش‌گرا (موبایل‌اول).
- سرویس API: FastAPI + Python برای نوع‌دهی قوی (Pydantic)، پشتیبانی آسان از موتورهای محاسباتی و OpenAPI خودکار.
- پایگاه داده: PostgreSQL 16 با افزونه‌های `btree_gist` و `uuid-ossp`.

## پیامدها
- **مثبت:** تولید خودکار کلاینت TypeScript از OpenAPI، امکان تعریف قیدهای دامنه‌ای پیشرفته در Postgres.
- **منفی:** وجود دو زبان (TS و Python) که نیازمند مدیریت قراردادهای نوع‌دهی از طریق OpenAPI است.
