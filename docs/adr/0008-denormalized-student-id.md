# ADR-8: وجود ستون student_id در تمام جداول داده دانش‌آموز

- **وضعیت:** پذیرفته شده
- **تاریخ:** 2026-10-23
- **مرجع:** بخش ۲٫۱ مشخصات پروژه

## زمینه و مسئله
برای اعمال یکپارچه سیاست‌های حریم خصوصی، فیلترینگ سطوح دسترسی (Authorization) و امکان فعال‌سازی Row-Level Security در پایگاه داده، لازم است مالکیت رکوردها بدون نیاز به JOIN‌های تودرتو مشخص باشد.

## تصمیم
تمام جداول مربوط به اطلاعات دانش‌آموز دارای ستون صریح `student_id` (غیرنرمال‌سازی عمدی) خواهند بود.

## پیامدها
- **مثبت:** اعمال آسان فیلترهای مجوز در تمام مخازن داده و سادگی پیاده‌سازی RLS.
- **منفی:** افزونگی داده‌ای اندک در برخی جداول فرعی.
